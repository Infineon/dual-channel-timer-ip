# Documentation

This directory contains documentation for the dual-channel timer, including
its architecture, programming model, and register map.

## Contents

- [`dual_channel_timer.adoc`](dual_channel_timer.adoc) - Documentation of the
  timer architecture, channel behavior, capture/compare operation, interrupts,
  programming model, and register reference.

Start with `dual_channel_timer.adoc` when reviewing the timer architecture,
counting and reload behavior, external trigger modes, or register access model.
